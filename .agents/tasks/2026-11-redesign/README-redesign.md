# Руководство редактора: публикация материалов в новом дизайне СНТ «Орбита»

Данное руководство предназначено для редактора сайта (роль `snt-editor`) и членов правления, публикующих новости, объявления, протоколы и отчеты на сайте https://cnt-orbita.ru/.

---

## 1. Структура публикации (Page Bundle)

Каждая новая публикация создается в отдельной подпапке внутри `content/post/<slug>/`:
```text
content/post/
  └── 2026-07-itogi-sobraniya/
      ├── index.md           # Основной текст статьи и метаданные
      ├── cover.jpg          # Обложка новости (опционально, пропорции 16:9)
      ├── protokol.pdf       # Прикреплённый PDF-документ (опционально)
      └── doverka.docx       # Бланк заявления или доверенности (опционально)
```

---

## 2. Стандартный шаблон Front-Matter (метаданные статьи)

В начале файла `index.md` обязательно указывается блок параметров в формате YAML:

```yaml
---
title: "Итоги очередного общего собрания членов СНТ «Орбита»"
slug: "itogi-ocherednogo-obshhego-sobraniya-2026"
date: 2026-07-06T12:00:00+03:00
description: "Утверждена смета на 2026–2027 годы, избран новый состав Правления и Ревизионной комиссии. Протокол заседания №32."
categories: ["Собрания и выборы", "Правление и отчёты"]
protocol: "32"
featured: false

# Прикреплённые официальные документы (отображаются в виде удобных карточек скачивания)
documents:
  - title: "Протокол общего собрания №32 от 05.07.2026"
    url: "protokol-32.pdf"
    type: "PDF"
    size: "420 КБ"
  - title: "Утверждённая смета расходов на 2026–2027 гг."
    url: "smeta-2026-2027.pdf"
    type: "PDF"
    size: "310 КБ"

# Боковой виджет собрания (опционально, для анонсов голосований)
meeting:
  title: "Очное собрание"
  description: "Регистрация участников у здания Правления"
  dates:
    - label: "Дата и время"
      value: "4 июля в 12:00"
    - label: "Место"
      value: "Детская площадка СНТ"
  btnText: "Скачать бюллетень (PDF)"
  btnUrl: "#files"
---

Текст статьи пишется чистым Markdown без использования сырых HTML-тегов...
```

## 3. 7 Канонических рубрик сайта

Чтобы в архиве и поиске сохранялся строгий порядок, используйте только утвержденные рубрики из списка ниже (до 2 рубрик на одну статью):

| Название рубрики | Когда использовать |
| :--- | :--- |
| **`Важное и срочное`** | Срочные аварии, отключения воды/света, экстренные предупреждения правления. |
| **`Собрания и выборы`** | Уведомления об общих собраниях, бланки бюллетеней, списки кандидатов, итоги голосований и кворум. |
| **`Правление и отчёты`** | Протоколы заседаний правления, отчеты ревизионной комиссии, финансово-экономические обоснования, акты. |
| **`Дороги и благоустройство`** | Ремонт подъездной и внутренних линий дорог, субботники, отсыпка щебнем, шлагбаумы, канавы. |
| **`Электроэнергия и тарифы`** | Новые тарифы АО «ПСК», диапазоны потребления, передача показаний счетчиков, модернизация электросетей. |
| **`Пожарная безопасность и МЧС`** | Особый противопожарный режим, правила разведения костров, состояние пожарных водоемов и пирсов. |
| **`Праздники и жизнь СНТ`** | День Победы, Бессмертный полк, детские праздники, мастер-классы, бытовые объявления садоводов. |

## 4. Использование полезных шорткодов

Внутри текста статей доступны готовые визуальные блоки:

### 1. Информационные плашки (`callout`)
```markdown
{{< callout type="info" title="Порядок получения бюллетеней" >}}
Бюллетени для заочного голосования можно получить лично в помещении Правления по субботам с 12:00 до 14:00 либо скачать бланк внизу статьи.
{{< /callout >}}

{{< callout type="warn" title="Внимание: дедлайн приёма голосов" >}}
Заполненные бюллетени принимаются строго до 3 июля 2026 года до 20:00!
{{< /callout >}}

{{< callout type="success" title="Кворум состоялся" >}}
В голосовании приняли участие 214 участков из 334 (64,1%), решения собрания имеют законную юридическую силу.
{{< /callout >}}
```

### 2. Карточка скачивания документа (`doc`)
```markdown
{{< doc title="Бланк доверенности на право голоса (форма СНТ)" url="doverka.docx" type="DOCX" size="24 КБ" >}}
```

### 3. Банковские реквизиты (`requisites`)
Вставляет карточку с официальными реквизитами расчетного счета СНТ и кнопкой быстрого копирования:
```markdown
{{< requisites >}}
```

### 4. Вставка изображений (`figure`)
Автоматически конвертирует изображение в формат WebP и подбирает адаптивные размеры:
```markdown
{{< figure src="subbotnik.jpg" alt="Садоводы на весеннем субботнике" caption="Субботник 10 мая: уборка береговой линии озера" >}}
```

## 5. Управление баннером важного события на главной странице (`hugo.yaml`)

Главный баннер на первом экране (`heroBanner`) настраивается в файле `hugo.yaml`:

```yaml
params:
  heroBanner:
    enabled: true                                       # Включить/выключить баннер
    expiresAt: '2027-07-05T23:59:59+03:00'              # Дата, после которой баннер автоматически скроется
    tag: 'Общее собрание 2026'                          # Метка над заголовком
    datesLabel: 'Заочно: до 3 июля · Очно: 4 июля'     # Сроки
    title: 'Очередное общее собрание членов СНТ'       # Главный заголовок
    description: 'Выборы органов управления и смета'   # Описание
    showProgress: true                                  # Показать полосу кворума
    progressLeftLabel: 'Собрано 214 из 334 участков'   # Подпись слева
    progressRightLabel: 'Кворум 64% (состоялся)'        # Подпись справа
    progressPercent: 64                                 # Процент заполнения полосы
    primaryBtnText: 'Скачать бюллетень (PDF)'           # Кнопка 1
    primaryBtnUrl: '/p/itogi-ocherednogo-obshhego-sobraniya-2026/#files'
    secondaryBtnText: 'Повестка и смета'                # Кнопка 2
    secondaryBtnUrl: '/documents/'
```

## 6. Проверка сборки перед публикацией

Перед коммитом изменений запустите локальную сборку сайта:
```bash
/opt/homebrew/bin/hugo --minify
```
Код возврата должен быть `0`, а в выводе консоли не должно быть ошибок `ERROR`.
