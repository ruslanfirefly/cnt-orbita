# Hugo-разработчик сайта СНТ «Орбита» (snt-tech)

Скил отвечает за комплексное техническое сопровождение портала СНТ «Орбита» на базе **Hugo Extended** (бинарник `/opt/homebrew/bin/hugo`).
Спецификация составлена на основе архитектурного руководства арт-директора (`.agents/tasks/2026-11-redesign/new_design/recomendations.md`) и дизайн-пакета из 5 шаблонов.

---

## 1. Архитектура проекта и принцип изоляции темы

* **Git Submodule темы**: тема подключена в `themes/hugo-theme-stack/`.
  ⚠️ **Строго запрещено напрямую редактировать файлы в папке `themes/`**.
  Все изменения производятся исключительно путем переопределения (override) в корневой структуре проекта:
  * Базовые шаблоны, разметка страниц и partials: `layouts/`
  * Дизайн-система SCSS и скрипты: `assets/scss/main.scss`, `assets/js/main.js`
  * Статические ассеты (логотипы, фавиконы, QR-коды): `static/`
  * Конфигурация: `hugo.yaml`

## 3. Дизайн-система и правила верстки (`assets/scss/main.scss`)

* **Цветовая палитра бренда**:
  * Основной тон: официальный **Navy Ink** (`#17233b`) на холодном светло-сером фоне (`#f3f7fb`), белые карточки (`#ffffff`).
  * Акцент: глубокий бирюзовый **Cyan** (`#06b6d4` / `#0891b2` / `#0e7490`).
  * Сигнальные цвета: **Emerald Green** (`#059669`) для кворума и оплат, **Amber** (`#d97706`) для сроков и предупреждений, **Danger** (`#dc2626`) для PDF и аварийных служб.
* **Двухрежимная тема (`data-theme="light|dark"`)**:
  * Контрастность текста не ниже WCAG AA/AAA (6.3:1 – 10.9:1). Исключен баг низкого контраста телефонной трубки в тёмной теме.
  * Синхронизация с системным `prefers-color-scheme` и сохранение в `localStorage` (`cnt_theme` / `orbita-theme`).
  * Защита от FOUC через инлайн-скрипт в `<head>`.
* **Режим крупного шрифта «А+» для пожилых садоводов (`data-font="large"`)**:
  * Масштабирование шрифта до **114%** (`html[data-font="large"]`).
  * Все интерактивные элементы и тач-таргеты имеют высоту **не менее 44–52 px**.
  * Сохранение в `localStorage` (`cnt_font` / `orbita-font`).
* **Жесткий контроль размеров SVG-иконок**:
  * Каждая иконка обязана иметь строго ограниченные размеры в CSS:
    * `.meta-badge svg`: 15×15 px
    * `.act-btn svg`: 17×17 px
    * `.side-card h3 svg`: 17×17 px
    * `.callout-ic svg`, `.alert-icon svg`: 20×20 px
    * `.doc-dl svg`, `.doc-btn svg`: 17×17 px
    * `.prose svg`: не более 24×24 px
* **Идеальная типографика списков (`.prose ul`, `.prose ol`)**:
  * Отступы: `margin: 0 0 20px; padding-left: 24px;`
  * Межстрочный интервал: `line-height: 1.65; margin-bottom: 8px;`
  * Маркеры: `.prose li::marker { color: var(--cyan-deep); font-weight: 700; }`
  * Ссылки на PDF/DOCX внутри текста автоматически получают цветные бейджи формата.

## 7. Шорткоды проекта (`layouts/shortcodes/`)

1. **`callout.html`**: Информационные выноски (`info`, `warn`, `success`):
   ```markdown
   {{< callout type="info" title="Порядок выдачи бюллетеней" >}}Текст...{{< /callout >}}
   ```
2. **`doc.html`**: Карточка скачивания файла с форматом и размером:
   ```markdown
   {{< doc title="Устав СНТ" file="ustav.pdf" ext="pdf" size="1.4 МБ" desc="Действующая редакция" >}}
   ```
3. **`candidates.html`**: Сетка кандидатов в органы управления СНТ.
4. **`requisites.html`**: Банковские реквизиты СНТ с кнопкой копирования.
5. **`figure.html`**: Адаптивные картинки `<picture>` с автоматическим WebP.
6. **`columns.html`**: Flex-колонки с разделителем `<--->`.
7. **`alert.html`**: Совместимость со старыми записями (`info`, `warning`, `danger`, `success`).

## 8. Чеклист проверки сборки и Quality Gate

Перед каждым коммитом в ветку `redesign-2026-11`:
1. **Чистовая сборка без предупреждений и ошибок**:
   ```bash
   /opt/homebrew/bin/hugo --minify
   ```
2. **Проверка внутренних ссылок**: все ссылки должны разрешаться локально (100% валидность, отсутствие 404).
3. **Проверка размеров иконок**: ни один SVG не должен превышать свои лимиты (15–20 px), никаких растягиваний на весь экран.
4. **Проверка списков**: маркированные и нумерованные списки обязаны иметь кастомные маркеры `::marker` цвета `var(--cyan-deep)` и отступы `24px`.
5. **Проверка интерактивных сценариев**: модалка СБП открывается, тост копирования реквизитов работает, кнопки «А+» и темы переключаются без мигания.
6. **Документирование**: любые архитектурные правки фиксируются в `CHANGELOG-stage2.md`.
