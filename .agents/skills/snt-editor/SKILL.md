# Редактор сайта СНТ «Орбита» (snt-editor)

Скил предназначен для подготовки, редактирования и публикации новостей, объявлений и отчетов для жителей СНТ «Орбита».

---

## ✒️ Стиль и тональность
* **Аудитория**: садоводы и постоянные жители СНТ «Орбита».
* **Тон**: доброжелательный, открытый, уважительный, добрососедский.
* **Принцип**: перевод сложных официальных и юридических формулировок на живой и понятный язык без потери фактов и цифр.
* **Структура**: лаконичные абзацы, списки, выделение ключевых дат, дедлайнов и сумм полужирным шрифтом.

---

## 📁 Структура публикации (Page Bundle)
Каждая новость создается в виде отдельной папки внутри `content/post/`:

```text
content/post/<slug>/
├── index.md           # Текст статьи
├── image1.jpg         # Иллюстрации (если есть)
└── document.pdf       # Прикрепленные PDF/DOCX (если есть)
```

> **Правило для slug**: только строчные латинские буквы и дефисы (например, `subbotnik-10-may-2026`, `nachalo-golosovaniya-2026`).

## 📝 Стандарт Front Matter (YAML)
В начале каждого `index.md` обязательно размещается блок YAML:

```yaml
---
title: "Понятный заголовок статьи"
slug: "nazvanie-stati"
date: 2026-06-20T12:00:00+03:00
description: "Краткий анонс для карточки в ленте новостей (1-2 емких предложения)."
categories:
  - "Объявление" # Доступные варианты: "Объявление", "Собрание", "Важное", "Дороги", "Электричество", "Безопасность", "Праздники"
draft: false
---
```

## 🛠 Реальные шорткоды проекта (Hugo Theme Stack)

### 1. Информационные плашки (`alert`)
Шорткод парный: `{{< alert "тип" >}}...{{< /alert >}}`.  
Поддерживаемые типы: `"info"` (по умолчанию), `"warning"`, `"danger"`, `"success"`.

```markdown
{{< alert "info" >}}
**Важная информация:** Прием показаний электросчетчиков осуществляется до 25 числа каждого месяца.
{{< /alert >}}

{{< alert "warning" >}}
**Внимание!** 15 мая с 10:00 до 16:00 будет отключение электроэнергии в связи с ремонтом трансформатора.
{{< /alert >}}
```

### 2. Изображения с автоконвертацией в WebP (`figure`)
Шорткод автоматически пережимает локальные картинки бандла и отдает WebP:

```markdown
{{< figure src="shema-proezda.jpg" caption="Схема объезда ремонтного участка дороги" alt="Схема объезда" >}}
```

### 3. Колоночная верстка (`columns`)
Разделитель колонок — `<--->`:

```markdown
{{< columns >}}
#### Вариант 1: Ямочный ремонт
* Срок выполнения: 3 дня
* Гарантия: 1 сезон
<--->
#### Вариант 2: Капитальное асфальтирование
* Срок выполнения: 2 недели
* Гарантия: 5 лет
{{< /columns >}}
```

### 4. Прикрепленные документы и файлы
```markdown
📥 **Документы для скачивания:**
* [Бюллетень голосования (PDF, 420 КБ)](byulleten.pdf)
* [Проект сметы на 2026 год (PDF, 1.2 МБ)](smeta-2026.pdf)
```

## ✅ Чеклист готовности перед публикацией
1. [ ] Папка создана в `content/post/<slug>/`.
2. [ ] `slug` на латинице, отражает суть события.
3. [ ] Дата и время установлены актуальные (с таймзоной `+03:00` или дата `YYYY-MM-DD`).
4. [ ] Поле `description` заполнено и подходит для превью на главной странице.
5. [ ] Категории выбраны из стандартного набора проекта.
6. [ ] В тексте нет сырого HTML — только Markdown и шорткоды.
7. [ ] Все упомянутые фото и PDF положены рядом в папку статьи.
