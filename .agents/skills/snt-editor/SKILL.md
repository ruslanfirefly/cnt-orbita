# Редактор сайта СНТ «Орбита» (snt-editor)

Скил предназначен для подготовки, редактирования, визуального оформления и публикации новостей, официальных объявлений, протоколов Правления и отчетов для садоводов и жителей СНТ «Орбита».

Руководство составлено на основе нового брендбука портала (Navy Ink `#17233b` + Cyan Accent `#06b6d4`) и рекомендаций арт-директора (`.agents/tasks/2026-11-redesign/new_design/recomendations.md`).

---

## 1. Тональность и редакционные стандарты

* **Целевая аудитория**: садоводы и постоянные жители посёлка в возрасте от 20 до 85+ лет.
* **Тон коммуникации**: уважительный, доброжелательный, открытый, добрососедский.
* **Главный принцип**: юридическая точность (нормы 217-ФЗ, формулировки протоколов, суммы смет) в сочетании с понятным языком. Избегайте сухой канцелярщины там, где можно объяснить суть простыми словами.
* **Визуальная гигиена**:
  * Категорический запрет на эмодзи в заголовках и кнопках интерфейса (никаких «📢 Внимание», «⚡ Срочно»). Для смысловых акцентов используются строгие системные бейджи и иконки дизайн-системы.
  * Лаконичные абзацы по 2–4 предложения, структурированные маркированные списки, выделение ключевых дат, дедлайнов и сумм полужирным шрифтом.
  * Запрет на сырой HTML в тексте — только чистый Markdown и официальные шорткоды темы.

## 2. Структура публикации (Page Bundle)

Каждая новость создается в отдельной директории внутри `content/post/<slug>/`:

```text
content/post/<slug>/
├── index.md           # Текст статьи и Front Matter
├── cover.jpg          # Обложка новости (16:9, не менее 1200x675 px, опционально)
├── protokol-31.pdf    # Прикрепленные PDF-сканы документов (опционально)
└── doverka.docx       # Бланки заявлений Word (опционально)
```

> **Правило для slug**: только строчные латинские буквы, цифры и дефисы (например, `subbotnik-10-may-2026`, `utverzhden-spisok-kandidatov-2026`).

## 3. Стандарт Front Matter (YAML) со всеми элементами оформления

В начале файла `index.md` обязательно размещается конфигурационный блок YAML:

```yaml
---
title: "Утверждён список кандидатов в органы управления СНТ «Орбита»"
slug: "utverzhden-spisok-kandidatov-2026"
date: 2026-06-05T12:00:00+03:00
description: "Список кандидатов в Правление и Ревизионную комиссию, утверждённый Протоколом заседания Правления №31 от 03.06.2026 года для включения в бюллетени."

# Рубрики (выбирать строго из 7 канонических рубрик сайта, до 2 шт.):
categories:
  - "sobraniya"
  - "pravlenie"

# Теги для поиска и перелинковки:
tags:
  - "Выборы 2026"
  - "Протокол №31"
  - "Кандидаты"

# Официальные атрибуты (выводятся в шапке статьи и на карточках):
protocol: "31"                                    # Номер протокола Правления
event_date: "Голосование: 20 июня – 4 июля 2026" # Сроки мероприятия или голосования

# Управление отображением карточки в лентах:
featured: true   # true — сделать главной большой карточкой слева на главной странице
pinned: true     # true — закрепить вверху архива новостей с бейджем «Закреплено»
urgent: false    # true — выделить янтарной рамкой (для аварий, ЧП, отключений света)

# Управление элементами страницы статьи:
show_toc: true             # true — показывать оглавление в правой липкой колонке
show_voting_widget: true   # true — показывать в сайдбаре виджет текущего голосования

# Официальные вложения (автоматически рендерятся внизу статьи карточками скачивания):
attachments:
  - title: "Протокол заседания Правления №31 от 03.06.2026"
    file: "protokol-31.pdf"
    ext: "pdf"
    size: "420 КБ"
    note: "Скан с оригинальной подписью и печатью"
  - title: "Бланк доверенности на голосование"
    file: "doverka.docx"
    ext: "docx"
    size: "24 КБ"
    note: "Официальный шаблон формы СНТ"

draft: false
---
```

## 5. Элементы оформления и шорткоды

### 5.1. Информационные плашки (`callout` и `alert`)

Используйте для выделения срочной информации, правил и результатов:

```markdown
{{< callout type="info" title="Порядок получения бюллетеней" >}}
Бюллетени для голосования выдаются лично в помещении Правления по субботам с 12:00 до 14:00.
{{< /callout >}}

{{< callout type="warn" title="Внимание: дедлайн сдачи голосов" >}}
Заполненные бланки принимаются строго до 3 июля 2026 года до 20:00!
{{< /callout >}}

{{< callout type="success" title="Кворум состоялся" >}}
В голосовании приняли участие 214 участков из 334 (64,1%). Решения имеют законную силу.
{{< /callout >}}
```

> **Обратная совместимость**: шорткод `{{< alert "info" >}}...{{< /alert >}}` также поддерживается автоматически.

---

### 5.2. Карточки документов для скачивания (`doc`)

Вместо голых синих ссылок вставляйте официальные карточки с бейджем формата, размером файла и кнопкой скачивания:

```markdown
{{< doc title="Устав СНТ «Орбита» (действующая редакция)" file="ustav.pdf" ext="pdf" size="1.4 МБ" desc="Утверждён общим собранием членов товарищества" >}}

{{< doc title="Бланк доверенности на голосование" file="doverka.docx" ext="docx" size="24 КБ" desc="Форма Word для заполнения" >}}
```

### 5.5. Фотографии и иллюстрации (`figure`)

Шорткод автоматически создает адаптивный тег `<picture>`, пережимает изображение в современный формат WebP и генерирует адаптивные размеры:

```markdown
{{< figure src="subbotnik.jpg" alt="Садоводы на субботнике" caption="Субботник 10 мая: уборка береговой линии озера" >}}
```

---

### 5.6. Колоночная верстка (`columns`)

Для сравнения вариантов смет или графиков работ:

```markdown
{{< columns >}}
#### Вариант 1: Асфальтовая крошка
* Стоимость: 480 000 ₽
* Срок службы: 2–3 сезона
<--->
#### Вариант 2: Капитальный асфальт
* Стоимость: 1 120 000 ₽
* Срок службы: 7–10 лет
{{< /columns >}}
```

---

### 5.7. Списки в тексте статьи

Списки в новом дизайне стилизуются автоматически:
* Маркированные списки (`- ` или `* `) получают аккуратные бирюзовые маркеры цвета `var(--cyan-deep)` и отступ `24px`.
* Нумерованные списки (`1. `, `2. `) оформляются полужирными цифрами с интервалом `1.65`.
* Любые прямые ссылки на файлы `.pdf` или `.docx` в тексте (`[Анкета кандидата](anketa.pdf)`) автоматически снабжаются цветными мини-бейджами `PDF` / `DOCX`.

## 6. Чеклист редактора перед отправкой в публикацию

1. [ ] Папка создана по стандарту `content/post/<slug>/`.
2. [ ] Название статьи понятное, без канцеляризмов и без эмодзи.
3. [ ] Поле `description` содержит 1–2 емких предложения (лид для соцсетей и превью).
4. [ ] Рубрики выбраны строго из 7 канонических (`vazhnoe`, `sobraniya`, `pravlenie`, `dorogi`, `electro`, `bezopasnost`, `zhizn-snt`).
5. [ ] Если есть номер протокола — заполнено поле `protocol: "31"`.
6. [ ] Все упомянутые документы (PDF/DOCX) положены в папку статьи и указаны в блоке `attachments:`.
7. [ ] Локальная тестовая сборка `/opt/homebrew/bin/hugo --minify` проходит без ошибок (`code 0`).
