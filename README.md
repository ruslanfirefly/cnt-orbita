# СНТ «Орбита» — Официальный портал садоводства (cnt-orbita.ru)

Добро пожаловать в репозиторий официального информационного портала **СНТ «Орбита»** (Ленинградская область, Ломоносовский район, Виллозское ГП, д. Малое Карлино, 383 участка).

Эта документация предназначена **для людей (председателя, редакторов, разработчиков) и ИИ-агентов**. Здесь подробно описано:
1. Как устроен проект и как его собирать.
2. Как включать, выключать и настраивать модули главной страницы (включая сезонный **Hero-баннер** собраний/объявлений).
3. Из каких готовых кирпичиков (UI-компонентов дизайн-системы **Navy & Cyan**) можно собирать новые баннеры и разделы.
4. Как создавать новости, протоколы и объявления с помощью Markdown и шорткодов.
5. Как редактировать справочные страницы (`content/page/`).

## 1. Архитектура и быстрый старт

Сайт работает на статическом генераторе **Hugo Extended** с **собственной автономной темой оформления** (без внешних тем и git-подмодулей) и компилятором стилей **Dart Sass**.

### Зависимости окружения (macOS / Linux)
- **Hugo Extended** (`v0.153.0+`, на macOS: `/opt/homebrew/bin/hugo`)
- **Dart Sass** (`brew install dart-sass`, бинарник `sass` должен быть в `PATH`)

### Основные команды
```bash
# Локальный сервер для разработки (с живой перезагрузкой):
/opt/homebrew/bin/hugo server -D

# Чистовая production-сборка в папку public/ (код выхода 0, без предупреждений):
/opt/homebrew/bin/hugo --cleanDestinationDir --minify
```

### Карта папок проекта
```text
cnt-orbita/
├── hugo.yaml                  # Главный конфигурационный файл (реквизиты, телефоны, баннеры, меню)

├── GEMINI.md / AGENTS.md      # Инструкции для ИИ-агентов
├── assets/
│   ├── scss/main.scss         # Единая дизайн-система сайта (Navy & Cyan, Светлая/Тёмная темы, режим А+)
```

## 2. Управление модулями главной страницы (`hugo.yaml`)

Главная страница (`layouts/index.html`) состоит из независимых модулей, которые управляются через секцию `params:` в файле `hugo.yaml` без редактирования HTML-шаблонов.

---

### 2.1. Модуль сезонного Hero-баннера (`params.heroBanner`)

Шаблон: `layouts/partials/hero-banner.html`  
Стили: `.hero-banner` в `assets/scss/main.scss`

Этот крупный тёмно-синий градиентный баннер в верхней части главной страницы используется для самых важных сезонных событий СНТ: **Общего собрания и голосования, кампании по сбору взносов, весенней просушки дорог или важных аварийных объявлений**.

#### Как включить или выключить баннер
В файле `hugo.yaml` найдите секцию `params.heroBanner`:
- Чтобы **скрыть баннер** (штатный режим, когда нет активного собрания): установите `enabled: false`.
- Чтобы **включить баннер**: установите `enabled: true`.
- **Автоматическое выключение по дате (`expiresAt`)**: если указать дату и время в формате ISO-8601 (например, `expiresAt: '2026-07-05T23:59:59+03:00'`), клиентский скрипт в `assets/js/main.js` автоматически скроет баннер у всех посетителей сразу после наступления дедлайна, даже если сайт не пересобирали.

#### Анатомия Hero-баннера (из каких элементов он состоит)
```text
┌───────────────────────────────────────────────────────────────────────────────────┐
│ [📢 ОБЩЕЕ СОБРАНИЕ 2026] (.hero-tag)   Заочно: 20 июня — 3 июля (.hero-dates)     │
│                                                                                   │
│ Заголовок баннера (.hero h1)                                  ┌─────────────────┐ │
│ Поясняющий текст под заголовком (.hero p)                     │ Основная кнопка │ │
│                                                               │ (.hero-btn-     │ │
│ ┌───────────────────────────────────────────────────────────┐ │  primary)       │ │
│ │ Левая подпись: значение     Правая подпись: значение      │ ├─────────────────┤ │
│ │ [████████████████████████████░░░░░░░░░░░░░] (.quorum-bar) │ │ Вторая кнопка   │ │
│ └───────────────────────────────────────────────────────────┘ │ (.hero-btn-     │ │
│   (.quorum-box — отображается если showProgress: true)        │  secondary)     │ │
│                                                               └─────────────────┘ │
└───────────────────────────────────────────────────────────────────────────────────┘
```

1. **`.hero-top`** (верхняя строка):
   - `tag` (`.hero-tag`) — янтарный бейдж с иконкой рупора (например, `Общее собрание 2026` или `Важное объявление`).
   - `datesLabel` (`.hero-dates`) — сроки проведения или дата (например, `Заочно: 20 июня — 3 июля · Очно: 4 июля в 12:00`).
2. **Текстовое ядро**:
   - `title` (`<h1>`) — главный заголовок баннера.
   - `description` (`<p>`) — краткое пояснение на 1–2 предложения.
3. **Блок прогресса / инфо-плашка (`.quorum-box`)**:
   - Включается флагом `showProgress: true` (при `showProgress: false` блок полностью скрывается, и баннер становится компактным).
   - `progressLeftLabel` и `progressRightLabel` — подписи над шкалой. Поддерживают тег `<b>...</b>`, который автоматически окрашивается в яркий бирюзовый цвет (`#67e8f9`).
   - `progressPercent` — число от `0` до `100`, задающее ширину бирюзово-изумрудной полосы заполнения `.quorum-fill`.
4. **Блок кнопок действий (`.hero-actions`)**:
   - `primaryBtn` (`.hero-btn.hero-btn-primary`) — яркая бирюзовая кнопка основного действия (`text` + `url`).
   - `secondaryBtn` (`.hero-btn.hero-btn-secondary`) — полупрозрачная кнопка второго действия (`text` + `url`). Если оставить `text: ""`, вторая кнопка не выводится.

#### Готовые пресеты `heroBanner` для разных случаев

**Вариант 1: Общее собрание членов СНТ (полный баннер со шкалой)**

### 2.2. Оперативная сводка инфраструктуры (`params.statusBar`)
Шаблон: `layouts/partials/status-bar.html`  
Полоса из 4 карточек под Hero-баннером. Управляется в `hugo.yaml`:
- `enabled: true / false`
- Каждый элемент в `items:` имеет:
  - `dot`: цвет индикатора (`'ok'` — зелёный, `'info'` — бирюзовый, `'warn'` — пульсирующий янтарный для аварий/отключений).
  - `label`: верхняя серая подпись.

Шаблон: `layouts/partials/emergency-strip.html`  
Отображается на планшетах и телефонах (`<= 960px`) сразу под шапкой. Настраивается в `hugo.yaml` (`params.emergencyStrip.enabled`, `title`, `subtitle`).

### 2.4. Быстрые сервисные плашки 3×2 (`layouts/partials/quick-grid.html`)
Сетка `.quick-grid` на главной странице содержит 6 карточек быстрого доступа (`/vznosy/`, `/electro/`, `/categories/dorogi/`, `/documents/`, `/pravlenie/`, `/komfort/`).
- Цвета иконок `.q-icon`: по умолчанию бирюзовый, модификаторы `.green`, `.amber`, `.navy`.
- Цвета бейджей `.q-badge`: по умолчанию бирюзовый, модификаторы `.green`, `.amber`.

### 2.5. Карточка реквизитов и модальное окно QR-кода (`params.requisites`)
Шаблоны: `layouts/partials/payment-card.html`, `layouts/partials/qr-modal.html`  
Все реквизиты (`inn`, `kpp`, `account`, `bank`, `bik`, `qrImageUrl`, `paymentTableUrl`) берутся из `params.requisites` в `hugo.yaml` и автоматически подставляются:
- На главную страницу;
- В раздел `/vznosy/`;
- В раздел `/contacts/`;
- В подвал сайта (`footer.html`);
- В модальное окно QR-кода СБП (`qr-modal.html`);
- В шорткод `{{< requisites >}}`.

## 3. Как создавать новости, объявления и протоколы (`content/post/`)

Каждая публикация создаётся как **Hugo Page Bundle** — отдельная папка внутри `content/post/<год>-<месяц>-<день>-<slug>/` (или `content/post/<slug>/`), внутри которой лежит файл `index.md` и все прикреплённые к новости файлы (`.pdf`, `.docx`, изображения).

### 3.1. Полный шаблон `index.md` (Frontmatter)

```yaml
---
title: "Утверждён список кандидатов в органы управления СНТ «Орбита»"
slug: "utverzhden-spisok-kandidatov-2026"
date: 2026-06-05T12:00:00+03:00
description: "Краткая аннотация новости (1–2 предложения) для карточек на главной, в архиве и в поиске."
categories:
  - "sobraniya"
  - "pravlenie"
protocol: "31"                 # Номер протокола (опционально — выводит бейдж «Протокол №31»)

# Флаги приоритета (опционально):
featured: true                 # true = сделать главной крупной новостью на главной странице
pinned: true                   # true = добавить бейдж «Закреплено»
urgent: false                  # true = выделить карточку янтарной рамкой и бейджем «Важно»

# Настройки боковой колонки статьи (опционально):
show_toc: true                 # Показывать оглавление статьи справа
show_voting_widget: false      # Показывать виджет голосования справа

# Прикреплённые документы (рендерятся в красивые карточки скачивания внизу статьи):
attachments:
  - title: "Протокол заседания Правления №31 от 05.06.2026"
    file: "protokol-31.pdf"    # Имя файла в папке поста ИЛИ полный путь от корня (/ustav/ustav.pdf)
    ext: "pdf"                 # pdf | docx | xls
    size: "420 КБ"
    note: "Официальный скан с печатью"
---

Текст новости в формате чистого Markdown...
```

> **Примечание о совместимости вложений:** шаблон статьи поддерживает как поле `attachments` (`title`, `file`, `ext`, `size`, `note`), так и старый формат `documents` (`title`, `url`, `type`, `size`).

### 3.3. Шорткоды для оформления статей (`layouts/shortcodes/`)

⚠️ **Важное правило:** не используйте сырой HTML внутри Markdown-файлов статей (`content/post/**/index.md`). Используйте штатный Markdown и следующие шорткоды:

#### 1. Информационная выноска `callout` (с заголовком и иконкой)
Доступные типы `type`: `info` (бирюзовый, по умолчанию), `warn` (янтарный), `success` (зелёный).
```markdown
{{< callout type="info" title="Порядок выдачи бюллетеней" >}}
Получить бумажный бюллетень можно в доме Правления каждую субботу с **12:00 до 14:00**. При себе необходимо иметь паспорт и членскую книжку.
{{< /callout >}}
```

#### 2. Компактное уведомление `alert`
Доступные типы (первый параметр): `info`, `warning`, `danger`, `success`.
```markdown
{{< alert "warning" >}}
**Внимание!** Наличные деньги в кассу СНТ не принимаются согласно ст. 14 ФЗ-217.
{{< /alert >}}
```

#### 3. Карточка документа для скачивания `doc` внутри текста статьи
```markdown
{{< doc title="Бланк доверенности на голосование" file="/obraztsy-dokumentov/doverennost_golosovanie.pdf" ext="pdf" size="136 КБ" desc="Заверяется председателем СНТ бесплатно" >}}
```

#### 4. Блок банковских реквизитов СНТ `requisites`
Выводит интерактивную карточку реквизитов с кнопками копирования ИНН, Р/с, БИК в 1 клик и кнопкой вызова QR-кода СБП:
```markdown
{{< requisites >}}
```

#### 5. Две или три колонки `columns`
Разделяйте колонки маркером `<--->`:
```markdown
{{< columns >}}
### Левая колонка
Текст или список первой колонки.
<--->
### Правая колонка
Текст или список второй колонки.
{{< /columns >}}
```

#### 6. Иллюстрация с подписью `figure` (с авто-конвертацией в WebP)
```markdown
{{< figure src="photo.jpg" alt="Ремонт главной дороги" caption="Отсыпка щебнем центральной аллеи, июнь 2026 г." >}}
```

## 4. Каталог компонентов дизайн-системы (для создания новых блоков и страниц)

Все стили собраны в `assets/scss/main.scss`. Если вам нужно собрать новый баннер, информационный блок или справочную страницу в `layouts/`, используйте готовые классы дизайн-системы **Navy & Cyan**.

### 4.1. Цветовые переменные (CSS Custom Properties)
Автоматически адаптируются под светлую (`:root`) и тёмную (`[data-theme="dark"]`) темы:
- **Фоны и поверхности**: `var(--bg)`, `var(--bg-elev)`, `var(--bg-soft)`, `var(--card)`, `var(--navy)` (`#0f1b2d`), `var(--grad-hero)`.
- **Текст**: `var(--ink)` (основной), `var(--ink-soft)` (вторичный), `var(--muted)` (приглушённый).
- **Границы и тени**: `var(--line)`, `var(--line-strong)`, `var(--shadow-sm)`, `var(--shadow-md)`, `var(--shadow-lg)`.
- **Акценты**:
  - Бирюзовый (Cyan): `var(--cyan)`, `var(--cyan-deep)`, `var(--cyan-soft)`, `var(--cyan-border)`.
  - Изумрудный (Emerald / Green): `var(--emerald)`, `var(--emerald-soft)`, `var(--emerald-text)`, `var(--green)`, `var(--green-soft)`.
  - Янтарный (Amber): `var(--amber)`, `var(--amber-soft)`, `var(--amber-text)`, `var(--amber-border)`.
  - Красный (Danger): `var(--danger)`, `var(--danger-soft)`, `var(--danger-text)`.

### 4.2. Готовые строительные блоки (HTML-паттерны)

#### А. Градиентная шапка раздела с быстрыми якорями (`.page-hero.page-hero-grad`)
Используется на всех справочных страницах (`/documents/`, `/electro/`, `/dorogi/`, `/pravlenie/`, `/vznosy/`, `/komfort/`, `/contacts/`, `/redaktsiya/`). В светлой теме автоматически окрашивается в светлый бирюзово-голубой градиент с тёмно-синим текстом, а в тёмной теме — в глубокий тёмно-синий градиент:
```html
<section class="page-hero page-hero-grad">
  <h1>Заголовок раздела</h1>
  <p>Краткое описание раздела на 1–2 строки.</p>
  <div class="jump-pills" role="navigation" aria-label="Быстрый переход по разделу">
    <a class="jump-pill" href="#section-1">Первая секция</a>
    <a class="jump-pill" href="#section-2">Вторая секция</a>
  </div>
</section>
```

#### Б. Заголовок секции с иконкой (`.sec-block` + `.sec-head`)
Всегда указывайте явные атрибуты `width="22" height="22"` и `aria-hidden="true"` у SVG-иконки внутри `.sec-title`:
```html
<section class="sec-block" id="section-1">
  <div class="sec-head">
    <h2 class="sec-title">
      <svg width="22" height="22" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2.2" aria-hidden="true">
        <path d="M14 2H6a2 2 0 0 0-2 2v16a2 2 0 0 0 2 2h12a2 2 0 0 0 2-2V8z"/><path d="M14 2v6h6"/>
      </svg>
      Название секции
    </h2>
    <span class="sec-sub">Пояснение справа от заголовка</span>
  </div>
  <!-- Контент секции -->
</section>
```

#### В. Карточки цифр и тарифов (`.tariff-grid` + `.tariff-card`)
Отлично подходят для отображения тарифов, вариантов смет, размеров взносов или параметров инфраструктуры (модификатор `.featured` выделяет карточку бирюзовой рамкой):
```html
<div class="tariff-grid">
  <div class="tariff-card featured">
    <div class="t-head">
      <div class="t-name">Название карточки</div>
      <span class="t-badge">Акцентный бейдж</span>
    </div>
    <div>
      <span class="t-price">1 800 000</span>
      <span class="t-unit">₽</span>
    </div>
    <div class="t-note">Поясняющий текст внизу карточки с деталями.</div>
  </div>
</div>
```

#### Г. Карточки документов и информационных блоков (`.doc-grid` + `.doc-card`)
Универсальная двухколоночная сетка карточек для документов (`pdf`, `docx`, `xls`) или справочных карточек:
```html
<div class="doc-grid">
  <article class="doc-card">
    <div class="doc-left">
      <div class="doc-ext pdf">PDF</div>
      <div class="doc-info">
        <div class="doc-title">Устав СНТ «Орбита»</div>
        <div class="doc-desc">Описание документа или справочного пункта.</div>
        <div class="doc-meta">
          <span>Редакция 2023 г.</span>
          <span class="sep"></span>
          <span>PDF · 10.6 МБ</span>
        </div>
      </div>
    </div>
    <a class="doc-btn" href="/ustav/ustav.pdf" target="_blank" rel="noopener">Скачать</a>
  </article>
</div>
```

#### Д. Акцентный баннер быстрых действий (`.electro-ActionBar`)
Горизонтальный блок с бирюзовой боковой линией и кнопками действий (`.eab-btn.primary` и `.eab-btn.ghost`):
```html
<div class="electro-ActionBar">
  <div class="eab-text">
    <h3>Заголовок важного блока действий</h3>
    <p>Поясняющий текст для садоводов.</p>
  </div>
  <div class="eab-btns">
    <a class="eab-btn primary" href="/vznosy/">Основная кнопка</a>
    <a class="eab-btn ghost" href="/contacts/">Вторая кнопка</a>
  </div>
</div>
```

#### Е. Пагинация списков и рубрик (`layouts/partials/pagination.html`)
Автоматически выводится внизу `/post/` и `/categories/<slug>/` при количестве карточек больше `pagination.pagerSize` (10 на страницу):
```go-html-template
{{ partial "pagination.html" . }}
```

#### Ж. Интерактивные JS-триггеры (работают автоматически на любой странице)
В `assets/js/main.js` подключены глобальные обработчики, которые можно использовать на любой кнопке:
1. **Копирование текста в 1 клик с всплывающим уведомлением (`#toast`)**:
   Добавьте класс `copy-btn` и атрибут `data-copy`:
   ```html
   <button class="req-pill copy-btn" type="button" data-copy="4720008674" data-label="ИНН 4720008674">
     <span class="k">ИНН:</span>
     <span class="v">4720008674</span>
   </button>
   ```
2. **Открытие модального окна с QR-кодом оплаты СБП**:
   Добавьте класс `btn-show-qr` к любой кнопке или ссылке:
   ```html
   <button class="qr-open-btn btn-show-qr" type="button">Показать QR-код СБП</button>
   ```

## 6. Чеклист проверки перед коммитом и релизом

1. **Никаких предупреждений при сборке**:
   Запустите `/opt/homebrew/bin/hugo --cleanDestinationDir --minify --logLevel info` — сборка должна завершаться с кодом `0` и `0 WARN`.
2. **Контроль размеров SVG-иконок**:
   Все декоративные SVG в кнопках, бейджах и заголовках должны иметь атрибуты `width` и `height` (`15–20px`) и `aria-hidden="true"`.
3. **Проверка светлой/тёмной темы и режима «А+»**:
   - Все цвета должны задаваться через CSS-переменные `var(--...)`, чтобы элементы оставались контрастными в обеих темах (`data-theme="light|dark"`) и масштабировались при включении крупного шрифта (`data-font="large"`).
   - В светлой теме градиенты `--grad-hero` и `--grad-art` являются светлыми бирюзово-голубыми (`#ffffff -> #e0f7fa`), поэтому заголовки и чипы `.jump-pill` внутри `.page-hero-grad`, `.search-hero` и `.vote-widget` используют тёмно-синий цвет `var(--ink)`. Тёмно-синяя заливка для них включается только в `[data-theme="dark"]` (единственное исключение — главный баннер `.hero` на главной странице, который всегда остаётся тёмно-синим в обеих темах).
4. **Порядок рубрик в новостях (`categories`)**:
   Первая рубрика в массиве `categories` определяет иконку и подпись карточки в ленте на главной странице. Всегда ставьте на первое место профильную рубрику статьи (`"Собрания и выборы"`, `"Дороги и благоустройство"`, `"Пожарная безопасность и МЧС"`, `"Правление и отчёты"`), а не общую `"Праздники и жизнь СНТ"`.
